HowThingsWork Uploader

A private tool that publishes How Things Work explainer videos to their creator's own YouTube channel.

What it does

How Things Work is a series of short vertical videos that explain everyday technology, made with digital papercraft models and a text-to-speech voice. HowThingsWork Uploader is a small script that runs on the creator's own computer. It:

  • uploads each finished episode to the creator's YouTube channel, with the title, description and tags the creator wrote;
  • schedules each video to publish at a set time, two videos a day;
  • reads the channel's existing video list so it doesn't upload the same video twice;
  • changes the privacy setting of the creator's own older videos when the creator asks it to.

It uses the YouTube Data API through YouTube API Services. Only the channel owner uses it: it has no other users, no sign-up and no public interface.
